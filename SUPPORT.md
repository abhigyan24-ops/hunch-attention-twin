# Getting Support for Hunch

Hunch is an open-source project maintained by volunteers and contributors.

## Channels

- **Installation help & Q&A:** [hunch_support@googlegroups.com](mailto:hunch_support@googlegroups.com)
- **Bug Reports & Issues:** [GitHub Issues](https://github.com/abhigyan24-ops/hunch-attention-twin/issues) — please search [Issue #28](https://github.com/abhigyan24-ops/hunch-attention-twin/issues/28) first
- **Discussions & Ideas:** [GitHub Discussions](https://github.com/abhigyan24-ops/hunch-attention-twin/discussions)
- **Security Vulnerabilities:** Follow [SECURITY.md](SECURITY.md) — *do not file public issues for security vulnerabilities*

## Response Time

This is a beta project maintained by one person. Expect responses within **a few days**, not hours.
