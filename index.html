Architectural Pillars

How your attention twin guards flow

Causal Disruption Engine

Hunch uses on-device causal inference (EconML-style double machine learning) to learn your specific attention curves: when you are resilient, when fatigue hits, and what each interruption truly costs.

Purely local mathematical twin

Quiet Lease Sync

When deep editor activity begins in VS Code, your laptop issues an ephemeral Quiet Lease to your phone via local end-to-end encrypted WebSocket. Non-critical alerts are buffered in silent digests.

Fail-open safety protocol

Editor Resume Assistance

When interruptions do break through, the VS Code extension logs salt-hashed file transition milestones. Returning to your editor restores your breadcrumbs without scanning any private code or file paths.

Instant context re-activation
