Zero Cloud • Local Pipeline

How the causal engine protects your flow.

Engineered for sub-10ms evaluation across Android, desktop, and IDE without exposing a single byte to an external server.

01

Daemon Collectors

Passively measures typing tempo, active window state, and IDE file diffs. Raw data is stored locally in SQLite with rolling TTL expiration.

VS Code & Desktop Daemon
02

Causal Estimator

Runs sub-10ms Bayesian evaluation with LightGBM and rule priors to predict interruption cost before the operating system posts the notification.

Sub-10ms Decision Speed
03

Quiet Lease Actuator

Silently intercepts notifications via Android NotificationListenerService. Holds distractions in a local encrypted buffer.

Native Android & Desktop
04

Contextual Digest

Releases queued notifications in a structured summary only when you naturally finish a task or take a planned break.

Uncompromising Ethics

Self-directed agency, not workplace surveillance.

Unlike corporate monitoring tools that report your keystrokes to your boss, Hunch answers only to you.

100% On-Device Privacy

No cloud backend. No telemetry servers. No user tracking. All model inference and data storage happen purely inside your device's memory.

Fail-Open Architecture

If the engine crashes, sleeps, or runs out of battery, all notifications fail open. You will never miss an urgent call from family, doctors, or alarms.

Beta Installation Notes & Troubleshooting
  • Android 13/14/15 Restricted Settings: If Android grays out Notification Access, go to Settings > Apps > Hunch > 3 dots (top right) > Allow restricted settings, then grant permission.
  • Windows SmartScreen: Since this is a community open-source beta, click More info > Run anyway.
