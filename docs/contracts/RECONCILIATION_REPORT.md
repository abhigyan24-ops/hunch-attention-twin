## Additional CCRs that W3 must not hide

1. **Pairing commitment order (SYNC_CONTRACT §§3–4):** a dumb forwarding relay drops a laptop offer sent before the phone joins. Current tests starting both peers together do not prove a late phone saw the original commitment before generating its share. Propose retained immutable initial offer delivered before accepting pair_join, or an explicitly versioned readiness exchange. Never repair ordering by accepting a fresh commitment after the phone share. Add late-join, replaced-offer, cancellation, expiry and role tests.
2. **Partial invalid batch vs cumulative ACK (§§6/7.2):** good events are applied while bad events are rejected, yet ACK promises every transmitted seq through the cursor was durably stored and mismatch drops the batch. Choose durable settled cursor with controlled rejection tombstones OR atomic batch rejection, and distinguish incompatible version from isolated malformed event. This is a contract choice; a highest-good-seq ACK is not automatically safe. Restart and valid-invalid-valid tests required.
3. **Clock sign (§7.1):** formula estimates peer-minus-self; conversion of incoming peer timestamps requires the inverse in that direction. Add positive/negative skew examples with explicit variable names before platform implementations.
4. **Ingest lockout identity (§9.1):** same remote port range is unspecified. Define bounded identity/window/reset semantics rather than inventing ranges. A loopback/global bucket is a possible explicit owner choice.
5. **Limits and controlled vocabularies:** explicitly define 32768-byte limit on entire decrypted `{mid,ts,b}` vs just b; cancellation/result/error detail token vocabulary and bounds. Recursive forbidden-key validation alone does not stop raw text in an allowed free-form string.
6. **Frozen artifact drift:** C0 commit 8eef3ee replaced earlier reference helpers/vectors/tests; its completion report says zero CCRs but no owner resolutions for these conflicts are present in the audited contract. Passing mock tests is not resolution. W3 must review actual schemas/mocks against the approved report; do not assume C0 needs to be generated from scratch or that existing code is complete.
