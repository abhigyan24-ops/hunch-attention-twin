# Hunch public beta preparation

This checklist covers the candidate after Antigravity's rename lands. Record the
final commit and the matching Release workflow run before publishing.

- [ ] Confirm ownership, institutional clearance, license, and copyright holder.
- [ ] Confirm repository name, maintainer contact, and private security reporting.
- [ ] Review historical fixture matches and resolve the private privacy audit.
- [ ] Confirm redistribution terms for the Gradle wrapper, icons, vendored
  Electron extractor, and any bundled ActivityWatch assets.
- [ ] Add the approved license, third-party notices, and community policies.
- [ ] Verify package metadata and release artifact names against the final rename.
- [ ] Scan the integrated candidate and all refs intended for publication.
- [ ] Build the candidate in a fresh release dry run and record its exact SHA.
- [ ] Install the Windows bundle, APK, and VSIX on clean target environments.
- [ ] Verify the desktop starts, its bundled engine is healthy, and the extension connects.
- [ ] Review the final draft release, including signing and upgrade continuity.
